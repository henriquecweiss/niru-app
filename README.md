# Niru

Página do Niru, caderno de treino para Android: força, cardio e alongamento, sem conta e sem anúncios.

- Página inicial: https://henriquecweiss.github.io/niru-app/
- Política de privacidade: https://henriquecweiss.github.io/niru-app/privacidade.html

O código do app não fica aqui. Para dúvidas sobre privacidade, abra uma issue neste repositório.

A fonte Estedad é distribuída sob a SIL Open Font License (`fonts/OFL-Estedad.txt`).
